# ⚔️ Katalog Senjata, Skill, dan Pemicu Otomatis (Agent Arsenal)

Dokumen ini memetakan seluruh kapabilitas dan alat eksekusi yang aktif pada sistem ini.

---

## 1. Alat Eksekusi Terminal (CLI Weapons)

| Senjata (CLI Tool) | Perintah Panggil | Fungsi Utama |
|---|---|---|
| **`omp` (Oh-My-Pi)** | `omp`, `omp "..."`, `omp -p "..."` | Terminal coding & research agent dengan Google Gemini native |
| **`typst`** | `typst compile file.typ` | Kompiler dokumen ilmiah modern, render matematika presisi tinggi |
| **`pandoc`** | `pandoc input.md -o output.docx` | Konverter dokumen markup serbaguna (Markdown ke DOCX/PDF) |
| **`uv`** | `uv run script.py` | Runtime & package manager Python ultra-cepat untuk simulasi numerik |
| **`git`** | `git status`, `git commit` | Kontrol versi kode dan naskah |

---

## 2. Matriks Skill Akademik & Skripsi

| Skill | Pemicu Otomatis | Fungsi Utama |
|---|---|---|
| **`proposal-skripsi`** | Diskusi judul, Bab 1 - 3, perumusan masalah | Panduan terstruktur menyusun draf proposal skripsi |
| **`skripsi-auditor`** | Review naskah, audit metodologi, verifikasi rumus | Peer-reviewer kritis penguji logika ilmiah dan data empiris |
| **`arxiv`** | Pencarian makalah ilmiah, preprint, query paper ID | Ekstraksi dan perbandingan literatur akademik global |
| **`sinta-scholar-search`** | Pencarian jurnal nasional SINTA 1 & 2, Garuda, Scholar | Protokol pencarian literatur terakreditasi dan validasi ISSN |
| **`grounded-citations`** | Klaim ilmiah, pencantuman bukti, daftar rujukan | Menjamin seluruh kutipan berdasar sumber nyata tanpa halusinasi |
| **`docx` & `pdf`** | Membaca, mengedit, atau konversi berkas tugas akhir | Manipulasi dokumen formal Word dan PDF |
| **`humanizer` & `no-ai-slop`** | Polish kalimat naskah, review gaya bahasa | Menghapus pola kalimat generik AI agar tulisan alami dan tajam |
| **`json-canvas`** | Diagram alir skripsi, visualisasi arsitektur | Manipulasi file `.canvas` Obsidian secara programatis |
| **`obsidian-markdown`** | Pengorganisasian catatan, wikilinks, frontmatter | Manajemen knowledge base terstruktur |

## 3. Matriks Skill Rekayasa Perangkat Lunak

| Skill | Pemicu Otomatis | Fungsi Utama |
|---|---|---|
| **`tdd`** | Pembuatan fitur baru, fungsi kalkulasi, modul logika | Siklus Test-Driven Development (Red-Green-Refactor) |
| **`diagnosing-bugs`** | Investigasi error, crash, test failure | Analisis akar masalah terstruktur sebelum perbaikan |
| **`domain-modeling`** | Desain entitas basis data, arsitektur modul | Pemetaan domain terstruktur dan ADR |
| **`code-review`** | Sebelum commit, pemeriksaan pull request | Audit kualitas kode, tipe data, dan keamanan |
| **`code-simplifier`** | Refactoring setelah implementasi fitur | Penyederhanaan kode agar bersih dan mudah dirawat |
| **`ui-ux-pro-max`** | Desain UI antarmuka, komponen frontend, styling | Penerapan standar UI/UX modern, aksesibilitas WCAG |
| **`security-audit`** | Input handling, otentikasi, perizinan | Audit keamanan terhadap kerentanan OWASP |
| **`ponytail`** | Seluruh proses koding harian | Menghindari over-engineering; solusi minimal yang bekerja tuntas |
| **`safe-change`** | Modifikasi modul berisiko tinggi / core logic | Memastikan backward compatibility dan keamanan data |
